# 🌍 General Preferences

General preferences control the language, appearance, amount of file information on screen, and saved batch queues.

[← Preferences overview](../preferences.md) · [Next: Libraries & naming →](libraries-and-naming.md)

## 🗣️ Language

**System language** follows the language selected by your operating system. Choose a specific language to keep Media Renamer in that language even when the system setting changes.

This changes interface text only. It does not translate provider metadata, filenames, or custom templates.

## 🎨 Appearance

**Automatic** follows the operating system’s Light or Dark appearance. **Light** and **Dark** keep the chosen appearance until you change it again.

**Colour theme** changes accent colours and ambience without changing Light/Dark mode. Classic, Ocean, Forest, Rose, and Amber are always available. Seasonal themes appear at the appropriate time of year; developer mode can expose them for testing.

Animations respect the operating system’s reduced-motion preference.

## 📋 File list

**Detailed** shows match evidence and detected media tags. It is the best choice while learning the app or investigating an unexpected result.

**Summary** concentrates on the current filename and proposed filename. It suits familiar batches where you still want to inspect every change.

**Compact** uses shorter rows for large batches. Important review and blocked states remain visible.

**Follow rename progress in the file list** keeps the active file near the middle of the list during an operation. Leave it off to preserve your current scroll position.

## 💾 Reusable batch queues

A queue remembers source paths and whether the batch belongs to TV or Movies. Loading it restores the file list without renaming, moving, or modifying anything on disk.

Create one with **Save queue** above the main file list. In Preferences, use **Load** to reopen it or the bin button to remove it.

A queue does not copy media. If a source has been moved, renamed, or deleted outside Media Renamer, that item may need to be added again.

## ✅ Suggested choices

For early use, choose **Detailed**, keep your preferred appearance on **Automatic**, and leave progress following off unless you regularly process long batches. Saved queues are most useful for recurring folders or batches you plan to finish later.
