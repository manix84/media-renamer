# Extras classifier example

**Status: Design example — Stage 3.**

This type classifies featurettes, interviews, deleted scenes, behind-the-scenes videos, trailers, shorts, and music videos. The reference example will map filename and folder evidence to Plex extra types.

Classifiers return a proposed type, title, confidence, and evidence. The host displays uncertain results and owns the final Plex directory and filename. Small videos are not automatically treated as samples or deleted without review.
