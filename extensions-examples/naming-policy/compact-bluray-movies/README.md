# Compact Blu-ray movie names

**Status: Runnable.**

This extension matches Blu-ray movies, adds a settings tab, and supplies compact folder and filename template defaults. It deliberately retains the title, year, edition, technical summary, and TMDB ID. The user may customize the defaults or return to them at any time.

The destination is separately selected and the host still performs invalid-character normalization, byte-safe title shortening, collision checks, preview, execution, and undo.
