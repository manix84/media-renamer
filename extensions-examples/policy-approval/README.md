# Policy and approval example

**Status: Design example — Stage 7.**

Policy extensions express review requirements for ratings, genres, destinations, overwrites, volumes, household rules, or uncertain matches. The reference example will require adult confirmation before moving media outside an approved library root.

Policies are declarative and explain every decision. Extensions cannot hide files, weaken core safeguards, or grant themselves execution permission. Conflicts resolve toward the safer outcome and remain visible to the user.
