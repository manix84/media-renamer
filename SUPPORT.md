# Support

Media Renamer is currently pre-release software maintained on a best-effort basis.

- For reproducible bugs, use the bug-report issue form.
- For feature ideas, use the feature-request issue form.
- For suspected vulnerabilities, follow `SECURITY.md` and report them privately.

Before posting, remove API keys, tokens, usernames, hostnames, private paths, media-library names, and other personal information. A small synthetic filename is preferable to a real library entry.
