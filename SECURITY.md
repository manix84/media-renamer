# Security Policy

## Supported versions

Media Renamer is pre-release software. Security fixes are made on the latest version only.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use [GitHub's private vulnerability reporting](https://github.com/manix84/media-renamer/security/advisories/new) instead.

Include only the minimum detail needed to reproduce the problem. Do not submit real provider credentials, private filesystem paths, media-library names, or personal data. You should receive an acknowledgement within seven days. A fix and disclosure timeline will depend on severity and complexity.
